## Quality criteria

Each future premium UI pass should explicitly assess:

- visual hierarchy;
- spacing and density;
- typography;
- icon and status-chip consistency;
- action prominence;
- responsive mobile/tablet/desktop behavior;
- modal and scroll behavior;
- empty/loading/error/success states;
- destructive-action warnings;
- accessibility and focus states;
- contrast and reduced motion;
- keyboard navigation;
- investor credibility;
- government/enterprise credibility;
- truthful wording.
